New Game Plus Walkthrough

This checklist is for the New Game Plus playthrough to complete the game. There will be a complete walkthrough added in a later version of the guide. Required tasks are needed for the Golden Completed Trophy. Optional tasks are extra content you can view in a second playthrough, but isn't required for the Golden Competed Trophy.

Required

  • Complete the Compendium
  • Beat the Secret Boss
  • Obtain Big Bro is Worried Trophy (Visit Nanako in the hospital 3 times)
  • Obtain Hardcore Risette Fan Trophy (Hear 250 of Rise's navigation lines)

Optional

  • See alternate school club Social Links
  • See alternate female Social Link routes (alternate Sun requires multiple playthroughs or Save Abuse)
  • See all Hot Spring Skills/Events
  • See all Night Events
  • Ace every exam
