Current Problems

Thank you to everyone who has sent me a message letting me know about problems they have run into while following the walkthrough. I have tested the walkthrough on both the PS Vita version and the next-gen rereleases, so I can confirm that there are no errors with the route used in this walkthrough. In order to help you stay on track, here are some tips that may help:

Tips to Stay on Track
  • Make sure to have backup saves in case you need to travel back a bit. If you save every 2 to 3 days in a different slot, then you can backup a whole month if needed, which can be very helpful if you get behind
  • Make sure you always have a Persona with the matching arcana for the Social Link you are hanging out with. There are also some events outside of Social Links where you can earn extra points. Just to be safe, always have Personas for Party Members, Justice, and Hierophant in your deck.
  • Try to get the exact same amount of points, or more for each Status Parameter/Social Link that I get, to stay as close as possible, or maybe even get ahead a little.
Known Problems

On June 15th, some people can't rank up with Justice. If this happens, see if you can get the relationship will become closer soon message on June 2nd. If not, then find a way to earn more points to rank up, probably replace a book with hanging out.

On September 4th, some people can't rank up Hierophant. If so, see if you can get the relationship will become closer soon message on August 22nd. If you can't, then find a time to earn more points so you can rank up, such as replacing reading a book with hanging out with Hierophant.

On October 21st, the Moon S.Link has a romance option. However, the romance option for Moon works differently than it does for the other girls. This has ended up confusing a lot of readers. Without spoiling what happens in the S.Link, the options that are written down for Moon are correct, even if it doesn't seem like it at first.
