Controls

Originally listed for the PS Vita, shown here with Xbox controller names: Cross = A, Circle = B, Square = X, Triangle = Y, L / R = LB / RB, Start = Menu, Select = View. On PC these controls can be remapped as you see fit (Esc, then Controls).
