Walkthrough Objectives

The main goal of this walkthrough is to complete the game 100% (The Golden Competed Trophy) in two playthroughs. There are two Trophies that are only possible to get in New Game Plus, which is why this walkthrough requires two playthroughs. Because of this, we have a lot of spare time to see content not necessary for 100%. This walkthrough was designed to see as much content in the first playthrough as possible, and experience everything else possible in New Game Plus. However, the objectives for each playthrough can be changed around if you prefer. There will be some work on your part, but this walkthrough is flexible enough for you to change things around to fit your needs. Here is the list of objectives this walkthrough will accomplish:

First Playthrough:

  • Obtain the Golden Ending
  • See every ending
  • Max every Social Link
  • Romance every girl (option included for platonic routes if desired)
  • See every event option (except Summer Festival)
  • Complete every Quest
  • Max all Status Parameters
  • Read all books
  • Finish the Mega Beef Bowl Challenge
  • Defeat the Reaper
  • Obtain every Costume
  • Win every prize from the Vending Machine
  • Make every Model
  • Obtain all Trophies not listed in New Game Plus

New Game Plus:

  • Complete the Compendium
  • Obtain the Hardcore Risette Fan Trophy
  • Beat the Secret Boss
  • Register 100 Skill Cards
  • See Alternate School Club Social Links
  • See all alternate female Social Link routes (optional for alternate Sun Social Link)
  • See all Summer Festival options
  • See all Bike Skills
  • Ace every exam
  • Obtain The Power of Truth Trophy
  • Obtain Big Bro is Worried Trophy
  • Obtain Golden Completed Trophy
