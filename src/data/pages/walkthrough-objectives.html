Walkthrough Objectives

The main goal of this walkthrough is to complete the game 100% (The Golden Completed Trophy) in two playthroughs. There are two Trophies that are only possible to get in New Game Plus, which is why this walkthrough requires two playthroughs.

12objectives in New Game Plus
2Trophies only possible in New Game Plus

Because of this, we have a lot of spare time to see content not necessary for 100%. This walkthrough was designed to see as much content in the first playthrough as possible, and experience everything else possible in New Game Plus.
