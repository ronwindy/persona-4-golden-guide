Persona Compendium

Formula

These are the formulas for how the game computes which Personas you can fuse. Note that these formulas only work for Normal and Triangle spreads.

Normal Spread

There are 2 separate calculations to determine the Persona you get. The first one is for the arcana, which you can find the possible combinations under the section of the arcana you need. Second is the level of the Persona, which is determined by the following formula: {(1st Persona Base Level) + (2nd Persona Base Level)} / 2 + 1 = (Resulting Level). You add the base levels of both Personas together, divide by two, and add one. The base level of each Persona can be found in the section of their respective arcana. The Persona you get is the one with the closest base level equal to or greater than the result you got. Note that the closest Persona to your result does not include Personas that are Special Fusions (more info down below). Here is an example of the fusion process:

Example: Throne + Siegfried = Byakko
Arcana: (1st Persona Arcana) + (2nd Persona Arcana) = (Resulting Arcana)
Result: (Justice) + (Strength) = (Temperance)
Level: {(1st Persona Base Level) + (2nd Persona Base Level)} / 2 + 1 = (Resulting Level)
Result: (49 + 63) / 2 + 1 = 57
Resulting Persona: The closest Temperance Persona that's base level is equal to or greater than 57 (excluding Special Fusions) is Byakko with a base level of 62

Triangle Spread

This one is a little more complex than Normal Spreads. In order to determine the arcana, you must first find the result of the first two Personas in a Normal Spread, then take the result and combine it with the third Persona's arcana in a Triangle Spread. The order of Personas is determined by the CURRENT level, not the BASE level. So the third Persona is the Persona with the highest current level. To find the level, use the following formula: {(1st Persona Base Level) + (2nd Persona Base Level) + (3rd Persona Base Level)} / 3 + 5 = (Resulting Level). You add the base levels of all three Personas together, divide by three, and add five. Just like a Normal Spread, the Persona you get is the one with the closest base level equal to or greater than the result you got (excluding Special Fusions). Here is an example:

Example: Senri + Throne + Loki = Lachesis
Arcana Step 1: {(1st Persona Arcana) + (2nd Persona Arcana)} = (Resulting Arcana) (Note: Using Normal Spread)
Arcana Step 2: (Resulting Arcana from Step 1) + (3rd Persona Arcana) = (Resulting Arcana) (Note: Using Triangle Spread)
Result Step 1: (Empress) + (Justice) = (Magician) (Note: Using Normal Spread)
Result Step 2: (Magician) + (Fool) = (Fortune) (Note: Using Triangle Spread)
Note: Order of Personas are determined by CURRENT level, not BASE level, with 3rd Persona being the highest
Level: {(1st Persona Base Level) + (2nd Persona Base Level) + (3rd Persona Base Level)} / 3 + 5 = (Resulting Level)
Result: (9 + 49 + 64) / 3 + 5 = 45.6
Resulting Persona: The closest Fortune Persona that's base level is equal to or greater than 45.6 (excluding Special Fusions) is Lachesis with a base level of 51

Same Fusion

Using the same arcana in a Normal or Triangle Spread will get you a Persona of the arcana you fused with. The same rules as above apply, with one exception: the Persona you get is the one with the closest base level equal to or LOWER than the resulting level. Make sure to keep that in mind.

Special Fusions

Personas that are Special Fusions don't use formulas. They only have one combination of Personas that you can use to fuse them. Every Persona that requires a Cross, Pentagon, and Hexagon Spread is a Special Fusion. However, there are also Special Fusions that require a Normal or Triangle Spread. More info can be found in the Special Fusion section, as well as the requirements to fuse them.
