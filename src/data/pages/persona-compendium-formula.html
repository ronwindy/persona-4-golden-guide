Formula

These are the formulas for how the game computes which Personas you can fuse. They only work for Normal and Triangle spreads.

1
Arcana

Look up the combination in the section of the arcana you need.

2
Level

Average the base levels with the formula for your spread, then pick the Persona that fits.

Normal Spread
(1st Base Level+2nd Base Level)÷ 2+ 1=Resulting Level

Add both base levels, divide by two, add one. Each Persona's base level is in the section of its arcana.

Pick the next one up
You get the Persona with the closest base level equal to or greater than your result. Special Fusions are never counted (see below).
Example
1st PersonaThroneJustice · base 49
+
2nd PersonaSiegfriedStrength · base 63
=
ResultByakkoTemperance · base 62
ArcanaJustice + Strength → Temperance
Level(49 + 63) ÷ 2 + 1 = 57

The closest Temperance Persona with a base level equal to or greater than 57 (excluding Special Fusions) is Byakko, base level 62.

Triangle Spread

A little more complex. For the arcana, first work out the result of the first two Personas as a Normal Spread, then combine that result with the third Persona's arcana as a Triangle Spread.

Step 1 · Normal Spread1st + 2nd → Arcana A
→
Step 2 · Triangle SpreadArcana A + 3rd → Result
Order matters
Order is decided by current level, not base level. The 3rd Persona is the one with the highest current level.
(1st+2nd+3rd)÷ 3+ 5=Resulting Level(base levels)

Add all three base levels, divide by three, add five. As in a Normal Spread, you get the closest base level equal to or greater than the result, excluding Special Fusions.

Example

→
Arcana step 2 · TriangleMagician + Fool → Fortune
Level(9 + 49 + 64) ÷ 3 + 5 = 45.6

The closest Fortune Persona with a base level equal to or greater than 45.6 (excluding Special Fusions) is Lachesis, base level 51.

The one exception
The same rules apply, except you get the closest base level equal to or LOWER than the resulting level. Keep that in mind.
Special Fusions

Special Fusions don't use formulas. Each has only one combination of Personas that fuses it.

Always special

Every Persona that requires a Cross, Pentagon or Hexagon Spread.

Sometimes special

Some Special Fusions only need a Normal or Triangle Spread.

More info, and the requirements to fuse each one, is in the Special Fusion section.
