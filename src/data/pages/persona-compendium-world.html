Persona Compendium

World

There is only one Persona of the World arcana: Izanagi-no-Okami. He can only be fused on a New Game Plus file, and requires a Dodecahedron Spread. To fuse Izanagi-no-Okami you need the following Personas:

Izanagi + Sandman + Nata Taishi + Girimehkala + Norn + Oukuninushi + Orthrus + Kartikeya + Mithra + Tzitzimitl + Cu Chulainn + Legion
