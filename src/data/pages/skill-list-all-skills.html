How Skills Stack

Some Skills are stronger versions of other Skills. Here is how they work:

3-turn buffs: recast extends
Skills that increase stats for 3 turns extend the time they are active if recast on the same ally/foe.
e.g. Tarukaja
Auto-Ma beats Auto
Auto-Ma Skills take priority over Auto Skills.
Auto-Matarukaja>Auto-Tarukaja
Charges: no recast
Power Charge and Mind Charge cannot be cast on an ally/foe that already has that Skill in effect.
Counters don't stack
Counter, Counterstrike, High Counter and accessories with the same effects do not stack. The strongest Skill/accessory takes priority.
Affinity overlap: one wins
Resist Skills (e.g. Resist Fire, Null Fire, Repel Fire, Absorb Fire) and accessories with the same effects can overlap with a Persona's innate affinity. Only one of these Skills, accessories or innate affinities is used, by this priority:
Drain / Absorb›Repel / Reflect›Nullify / Block›Resist / Strong›Blank or Weak
Evade beats Dodge
If both Dodge and Evade Skills or accessories are present, Evade takes priority.
Evade Fire>Dodge Fire
Boost + Amp: max 2
Boost and Amp Skills (e.g. Fire Boost, Fire Amp) and accessories with the same effects can stack, but only two at a time. Skills take priority over accessories.
Regenerate / Invigorate
Regenerate and Invigorate Skills can stack. Skills and accessories with the same effect do not stack.
Mage's Mark + Invigorate 1 restores only 3 SP per turn instead of 6 SP.
Growth doesn't stack
Growth Skills do not stack. Priority is given to the strongest Skill.
