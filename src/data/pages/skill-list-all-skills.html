Skill List

All Skills

This section lists every Skill, and what they do. The Skills here are sorted based on type. There is a separate sorting system used when changing Skills based on Shuffle Time or Fusion Forecast, however this sorting system isn't well known, so it won't be included in this guide. Here is the list of every Skill:

Legend

Skill: Skill Name.

Effect: Effect of Skill.

Power: Stat used to calculate damage of Skill.

Acc: Accuracy. Base percent chance of Skill landing.

Crit: Base percent chance of Skill landing a critical hit. Only applies to Physical Skills.

Cost: Cost to use Skill. All Skills cost SP, except Physical Skills cost HP.

Exclusive: Skill exclusive to listed Persona or Party Member. Exclusive Skills can't be inherited through fusion.

Enemy: Skill exclusive to listed enemy. Only applies to Enemy Exclusive Skills.

How Skills Stack

Some Skills are stronger versions of other Skills. Here is how they work:

  • Skills that increase stats for 3 turns (ex. Tarukaja) will extend the time the Skill is active if recast on the same ally/foe.
  • Auto-Ma Skills (ex. Auto-Matarukaja) takes priority over Auto Skills (ex. Auto-Tarukaja).
  • Power Charge and Mind Charge cannot be cast on an ally/foe that already has that Skill in effect.
  • Counter, Counterstrike, High Counter, and accessories with the same effects do not stack. The strongest Skill/accessory takes priority.
  • Resist Skills (ex. Resist Fire, Null Fire, Repel Fire, Absorb Fire) and accessories with the same effects can cause overlap with a Personas innate affinity. Only one of these Skills, accessories, or innate affinities are used, and they follow the following priority: Drain/Absorb, Repel/Reflect, Nullify/Block, Resist/Strong, Blank or Weak.
  • If both Dodge and Evade Skills (ex. Dodge Fire, Evade Fire) or accessories are present, Evade takes priority.
  • Boost and Amp Skills (ex. Fire Boost, Fire Amp) and accessories with the same effects can stack. However, only two of these can stack at a time, and Skills will take priority over accessories.
  • Regenerate and Invigorate Skills can stack. However, Skills and accessories with the same effect not stack (ex. Mage's Mark and Invigorate 1 will only restore 3 SP per turn instead of 6 SP).
  • Growth Skills do not stack. Priority is given to the strongest Skill.
