# Persona 4 Golden - 100% True Golden Walkthrough

A premium, high-energy game walkthrough guide for Persona 4 Golden, designed with a custom Neo-Brutalist "Midnight Channel" aesthetic.

## 🚀 Features

- **Midnight Channel Aesthetic**: Custom CRT scanlines, digital grain, and pop-art motifs.
- **Dynamic UI**: Staggered entrance animations and hover-triggered jitter effects.
- **Responsive Design**: Optimized for both desktop and mobile viewing.
- **Complete Walkthrough**: A 100% True Golden guide covering every day and dungeon.

## 🛠️ Tech Stack

- **Astro**: Modern static site builder.
- **Vanilla CSS**: Optimized for performance and custom design tokens.
- **Google Fonts**: Staatliches, Outfit, and Montserrat.
